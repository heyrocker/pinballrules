---
title: "How the rulesheets are organiaed"
---

Files on Github are stored in repositories. To start, go to [the homepage for the pinball rules repository.](https://github.com/heyrocker/pinballrules)

![A screenshot of the Pinball Rules repository on Github](images/homepage.png)

There are several tabs across the top, plus a listing of all the files and directories on the site. This is where we'll concentrate right now. One of the directories is named "docs" which is where the rulesheets are held. Click that and you will get a listing like this.

![A screenshot of the docs directory on Github](images/docs.png)


The rulesheets are divided into folders, with each folder representing one of the pinball manufacturers. Clicking a folder will reveal the rulesheets, and then clicking a rulesheet will open up its text.

![A screenshot of the rulesheets listing on Github](images/rulesheet.png)

This guide is contained in the contribute folder, and can be contributed to or edited just like the rulesheets themselves!

For more information, see [editing a rulesheet](editing) or [creating a new rulesheet](creating)
