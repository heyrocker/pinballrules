---
title: "Reporting issues"
---

To report an issue, [click the Issues tab](https://github.com/heyrocker/pinballrules/issues) from anywhere within the [Pinball Rulesheets Github repository](https://github.com/heyrocker/pinballrules/). This will take you to the Issues page, where you can click New issue at the top right to create your issue. Give your issue a title and description and then click Create. You should get an email when your issue is resolved.

Issues are a great way to report problems with existing rulesheets if you are unfamiliar with how to edit them, one of our contributors will fix those issues instead. It is also where you can report issues with the website like broken links or pages.
