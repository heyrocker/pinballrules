# pinballrules.github.io
Pinball rulesheet repository

This repo contains rulesheets for pinball machines which describe the features and scoring for specific games. These rulesheets were originally created on Tilt Forums, and when that site got shut down they were moved here where the community could maintain them. The associated website https://pinballrulesheets.com is generated from this content via Github Pages. 

This is a community maintained project. If you are interested in contributing, just make an issue asking for access and I'll add you.
